# ЕРМАКЪ AI

Самообучающийся ИИ-помощник для Windows. Живёт в окне: слева чат, справа — живая панель обучения (связи, статьи, корни, темп в реальном времени).

## Что умеет

- **Отвечает на вопросы** — через локальную модель (LM Studio) с проверкой фактов по интернету, а без неё — сам, из собственной базы знаний.
- **Самообучается 24/7** — читает статьи и книги (Википедия, Викитека, Project Gutenberg, новостной корпус), наращивает связи «нейронов». Всё обучение видно в реальном времени.
- **Понимает картинки** — перетащи файл в окно или вставь скриншот через Ctrl+V (нужна модель со зрением в LM Studio, например qwen2.5-vl).
- **Управляет компьютером** — «открой блокнот», «сделай скриншот», «двинь мышь в 500,300», «набери текст …» (по умолчанию выключено, включается командой «компьютер вкл»).
- **Пишет скрипты** — «напиши скрипт, который …» — готовый код сохраняется в папку scripts.
- **Дисциплина «одна задача»** — выбираешь новую задачу, предыдущая отменяется.
- **Метрика качества** — часть материалов не тренируется, а откладывается на тест: каждые ~3 минуты в ленте видно, какой процент слов модель предсказывает на невиданных текстах.

## Скачать

**Ермакъ max** (релиз v1.2-max) — всё-в-одном: программа **и** готовый обученный ИИ.
Внутри: 25+ млн связей (нейронов), 80 тыс. статей, словарь русского языка.
Распакуйте все файлы в одну папку, запустите `ЕРМАКЪ.exe` — умный с первой секунды.

Есть и лёгкая версия (`Ermak-AI.zip`, релиз v1.0) — программа без базы, учится с нуля.

Личные разговоры из опубликованной базы удалены.

- Windows 10/11 x64. Устанавливать .NET не нужно — всё уже внутри.
- Исходный код проекта публично не распространяется.

## Первые шаги

1. Запусти `ЕРМАКЪ-App.exe` — база знаний создастся сама.
2. «обучение 100м» — спринт обучения; «обучение стоп/старт» — пауза/продолжить; «что ты умеешь» — список команд.
3. (Необязательно) Поставь [LM Studio](https://lmstudio.ai), загрузи модель (например qwen3) — ответы станут глубже, картинки — понятнее.

## Безопасность

Управление компьютером и выключение ПК — только после явного разрешения («компьютер вкл»), выключение ПК — с подтверждением. Файл настроек `computer_use.txt` лежит рядом с программой.
